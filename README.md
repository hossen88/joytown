# JOY TOWN — موقع سيرفر FiveM

موقع تعريفي لسيرفر رول بلاي باسم **JOY TOWN** بتصميم داكن مع اللون الأساسي `#eeb71a`، ويشمل شاشة افتتاح بتأثير تحميل، هيرو تفاعلي لتبديل الشخصيات، كروت قصص بنافذة ثلاثية الأبعاد تعرض القصة والمسارات، قسم «قوانين المدينة»، قسم «الاختبار الالكتروني» لنموذج التقديم، خريطة مدينة تفاعلية، وقسم دخول السيرفر.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | هيكل الصفحة والمحتوى |
| `style.css` | كل الأنماط والتأثيرات (اللون الأساسي في أول الملف) |
| `app.js` | التفاعلات: الإنترو، تبديل الشخصيات، الكشف بالتمرير، الخريطة، النسخ |
| `server.js` | خادم محلي صغير لمعاينة الموقع (اختياري) |

## التشغيل محلياً

```bash
node server.js
```

ثم افتح: `http://localhost:4173`

أو افتح `index.html` مباشرة في المتصفح.

## أهم تعديلات الإعدادات (في أعلى `app.js`)

```js
const CONFIG = {
  server: 'joytown.roleplay.gg:30120',   // عنوان سيرفر FiveM
  discord: 'https://discord.gg/joytown', // رابط الديسكورد
  store: 'https://joytown.store',        // رابط المتجر
  discordWebhook: 'https://discord.com/api/webhooks/...' // استلام قصص اللاعبين
};
```

- زر **دخول السيرفر** يستخدم `fivem://connect/` تلقائياً مع العنوان أعلاه.
- زر **نسخ عنوان السيرفر** ينسخ نفس العنوان.
- غيّر البريد `support@joytown.gg` في الفوتر إن لزم.

## نافذة القصة

عند الضغط على أي بطاقة دور (شرطة/إسعاف/مجرم/ المواطن) تفتح نافذة تعرض القصة فقط:

- وصف الدور + قائمة المسارات (3 خطوات للتقدم داخل هذا المسار)
- زر **«قدّم اختبارك الآن»** يغلق النافذة ويمرّر مباشرة إلى قسم `#apply`

## الاختبار الالكتروني (نموذج التقديم)

قسم مستقل `#apply` (مكان «ذكريات المدينة» سابقاً) يحتوي نموذج التقديم **بدون تحديد دور**:

1. اسم اللاعب الكامل + عمره (13–99)
2. اسم الشخصية في السيرفر + عمرها (18–99)
3. قصة حياتها من سطرين (40 حرفاً فأكثر)

عند الإرسال:

- تُبنى **لقطة PNG** للتقديم على `canvas` (بدقة مضاعفة 2x، نص عربي RTL مع شريط أصفر)
- تصل رسالة Discord فيها:
  - **Embed مرتب**: العنوان + الوصف (الاسم/الشخصية/القصة) + التذييل والتوقيت — بدون حقول مزدحمة وبدون سطر الدور
  - **اللقطة مرفقة** كصورة في نفس الرسالة
- ثم تظهر شاشة نجاح داخل القسم.

**ملاحظات مهمة:**
- الروم المخصص لاستقبال الطلبات: أنشئ رابط Webhook من إعدادات الروم ← Integrations ← Webhooks.
- رابط الـ Webhook سري — من يملكها يستطيع إرسال رسائل لرومك؛ لا تنشره في مكان عام.
- لتبديل الرابط لاحقاً: غيّر `CONFIG.discordWebhook` في `app.js`.

## استبدال الصور

- **كروت القصص**: تستخدم الصور `11.png` (شرطة) / `22.png` (إسعاف) / `44.png` (مجرم) / `33.png` (مواطن) داخل `.story-art` — استبدل الملفات بنفس الأسماء لتغيير الصور. الخلفية السوداء في الصور تندمج تلقائياً مع البطاقة عبر `mix-blend-mode:screen`.
- **شخصيات الهيرو**: الصور `11.png` / `22.png` / `44.png` / `33.png` داخل `.character-layer` (نفس ترتيب البطاقات) — الخلفية السوداء تندمج عبر `mix-blend-mode:screen`.
- **اللقطة المرفقة للتقديم**: تُرسم برمجياً في `app.js` (`renderApplicationShot`) — عدّل الألوان والنصوص من داخل الدالة.

## النشر

ارفع الملفات الأربعة إلى أي استضافة ثابتة (Netlify / GitHub Pages / Cloudflare Pages) كما هي — لا يحتاج بناءً.

## التوافق

- يعمل على الجوال والتابلت وسطح المكتب.
- يدعم `prefers-reduced-motion` (يوقف الأنيميشن لمن يفضل ذلك).
- بدون جافاسكربت: تُخفى شاشة الافتتاح تلقائياً.
